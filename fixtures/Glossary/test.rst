Glossary terms
##############

Measure the current with an ammeter. Use the ampere meter instead.

The ATTDB holds the Attribute Database. Use the Attribute Table.

The BLE Host talks to the Bluetooth LE Host. Use the BLE radio. Bluetooth LE is fine.

The S132 Stack is old. The S132 SoftDevice is fine. It is qualified against Bluetooth® 5.0.

Flash the LED twice. A flashing LED shows errors. Flash the firmware to the device.

Double-check the pins. Verify the pins. The value was double-checked.

Read the Id and the id fields. The ID is unique. The --id option and #id anchor are not prose.

Charge the LiPo battery. Use lithium ferro-phosphate cells. The M4F core and the Cortex-M4F core.

Read the tag type 2 data. Install the nRF Connect extension for VS Code.

Connect the PC. Restart the PCs. Send an SPI command. Turn on a LED and A LED.

Build the subimage. Use the XO or XOSC. Use the XTAL and Xtal. The WFA certifies it.

Install NCS or NCSDK. The SPM and NSPM are old. The nRF5 Series and the nRF Series and the nRF9x Series.

Use the NRF52840 or Nrf52840 or nrf52840. Build for nrf52840dk/nrf52840. Use NRF Connect SDK. Use NPM1300.

The Nordic thingy:91 and NORDIC THINGY:91. Order two nRF52840 DKs. Use the baremetal or bare-metal option.

Do not flag ``BLE``, ``NCS``, or ``id`` in code.

Do not flag :ref:`BLE` or :c:func:`id` in a role.
